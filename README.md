# RTKDevilAutoReply

RTKDevilAutoReply is an Android application built with Kotlin and Jetpack Compose for notification-based automatic replies.

## Features

- WhatsApp automatic replies using supported notification reply actions.
- WhatsApp Business support where compatible.
- Telegram notification-based automatic replies.
- Telegram Bot API integration.
- Configurable automatic reply messages.
- Welcome messages and automation settings.
- Dashboard and settings interface.
- Android notification access integration.

## Requirements

- Android 12 or later.
- JDK 21.
- Android SDK.
- Gradle Wrapper included in this repository.
